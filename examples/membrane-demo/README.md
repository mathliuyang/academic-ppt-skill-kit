# 聚合物膜的交联设计

这套 4 页示例使用原创聚合物链示意和手工构造的教学数据。数据见 [CSV](demo-data.csv)。所有数值仅用于演示制图，无实物样品或实验来源。

打开 [可编辑 PPTX](report.pptx) 可以查看两组对照示意、内嵌数据的折线图、表格和逐页演讲者备注。[PDF](report.pdf) 可直接预览。PPTX 使用 PingFang SC，系统缺少该字体时可安装合适的中文字体或先查看 PDF。

[逐页讲稿 Word](speech.docx) · [大字讲稿 PDF](speech.pdf) · [逐页数据 JSON](report.json)。PPT 备注和两种讲稿的口述内容已通过一致性检查。
