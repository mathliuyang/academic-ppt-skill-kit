# 增删文献与局部改版

## 在现有报告里换一篇研究

- 以用户最后认可或刚传来的 PPTX 为底稿，另存分支。先读实际页序，列出保留、替换和连带受影响的页面。保留研究的主要内容和配图继续沿用。只有主问题变化影响到背景、目录、章节过渡、研究对比和总结时，才更新对应页面或备注。阅读结果若与用户对论文的初步归类不同，说明聚合物、对象或方法究竟在哪里改变，再据此调整共同比较轴。
- “选择能用的原图”通常按讲述价值取舍，优先正文关键图。“全图”则先从当前可得的原文逐图列目录。按最细可独立阅读的子图计数；整幅不可分的图算一项。正文与补充材料分开。目录清点、已放置位置和可读性分别核对。只覆盖某个大图的一个子图不能代表整组齐全，未取得的补充材料不能计入覆盖率。
- 将更多子图编成各有主题的证据页，或按用户要求放到备份。主讲与备份分开报覆盖，注意扩页后时长。图裁切完成后检查轴名、刻度、图例、单位、比例尺与相邻子图杂字；移动、缩放或换裁切时重新检查原生圈选、引线、中文释义、样品和颜色对应。跨研究对比时并列报告工况及样品，避免对不同比较条件强行排名。
- 页面标题和讲稿优先用具体且常见的学术表述。用“结构表征”“尺寸稳定性”“器件运行测试”等准确说明对象或方法，避免空泛栏目、随意缩写和反复使用“作者认为”。用“计算显示”“原位观察到”“由此推测”等合乎原文的动词保留论证边界。长度变化后重新检查换行。
- 逐图账本可用 `scripts/check_figure_coverage.py` 对照源清单与已放置记录，给出缺项与主讲/备份分布。它核对人工确认过的记录。每张图是否确实出现在相应页面以及裁切是否完整，仍需对照成品和原图查看。

## 只重排指定页面并统一全篇页码

- 用户提供的截图用于辨认修改页，用户传来的完整文件用于确定当前页序、正文、原生对象及备注。先记录允许改的页、对象、允许全篇改的公共组件和备注范围；通过页面标题、内容与同版截图确认定位。截图编号与文件页序不一致时按内容核对。
- 从邻近已认可页面提取颜色和用途、字体及字号、留白和公共组件。构图表达原有关系：对比用并列，组成用分层，因果用短流程。配色继承原稿的主色和强调色，正文空间优先，实际渲染检查中文断词、单位断行和词组拆分。
- 统一页码时同时核查本页、组、母版和版式中的字段、普通文本和继承对象。用实际属性、位置和显示判断，勿仅靠对象名或数字内容。正文按实际页序核对恰好一个可见页码，封面、致谢或其他例外依当前规则处理。注意叠放的旧号码有时在低分辨率导出里很难识别。
- 局部排版用副本。确认改动范围时用文件结构与实际渲染两种证据。前者能证明对象和备注未被重写，后者能发现字体替换、重叠与继承显示差异。全局修正页码时，比较未重排页的正文区域、背景、图和备注，并允许页码所在区域按授权变化。必要时记录导出器差异，避免把字体回退误判为改动正文。
- 排版任务保留原备注，包括为空的备注。用户要求完整讲稿时再补齐空备注，核查原备注是否过时。新导出的幻灯片 PDF 与 PPTX 同版，Word 和讲稿 PDF 取自同版备注或统一脚本。逐项验证文字、页序及中文字符的实际显示，特别是衬线字体与上下标。如果换了可靠导出器，重渲染最终交付文件并注明采用的检查方式。无需用 computer use 操作。

### 图清单格式

`inventory.csv` 列为 `paper,section,panel,expected`，例如 `study-a,main,Fig.2b,yes`。 `placements.csv` 列为 `paper,section,panel,slide,area`，例如 `study-a,main,Fig.2b,9,main`。`section` 用 `main` 或 `supplement`，`area` 用 `main` 或 `backup`。正文和补充的取得状态写进工作记录。缺失文件不建虚拟子图项。选择模式下用 `expected=no` 记录经判断不必展示的实际子图。

```sh
python scripts/check_figure_coverage.py inventory.csv placements.csv --slide-count 35
```

退出码 1 表示有缺项或登记不符，2 表示输入无效。只要一个子图既出现在主讲又出现在备份，就按主讲计一次。若用户明确要求每图都在主讲，额外检查结果里的 `backup_only`。
