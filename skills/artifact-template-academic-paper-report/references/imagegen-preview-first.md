# 整页生图设计，再重建可编辑 PPT

## 顺序与事实依据

新建报告和整套重设计默认核验论文，编排目录与证据，备齐原图和所需独立素材，生成并检查整套 ImageGen 设计稿，再按设计重建可编辑 PPT。全套使用本次选定的模板规范，封面、目录和结束页使用对应页型。只有用户要求先审核设计时才等待确认。局部修订按指定范围处理。

先从[参考库](template-library.json)和当次资料中确定所用视觉方案。一个报告采用一套公共框架，内容区可借鉴不同页型；不混用不同案例的页眉、校徽或页脚位置。当前用户要求与其最新认可的成品优先于较早的生成图。总结页、讨论页默认仍属于正文，不能因生成图偶发变化而自行换一套底部样式。

既有报告精修可沿用真实历史设计作内部结构参考，保留原工具调用与历史图像，明确本轮精修差异。过时预览即使确由imagegen生成，也不作为更新版成品或随最终ZIP交付；本轮通过QA的最终渲染与可编辑PPT是更新版成果。

`report.json` 是准确文字和讲稿源；科学原图与品牌文件是素材源。设计和重建映射保存为 `design-record.json`，按 [逐页设计记录](preview-data.md) 使用。生成像素不能改写已核对的内容，也不另建 OCR/页面状态机。预览审阅中合理精炼文案时同步更新数据；新增事实必须先核验，不能把生成器添加的内容直接当事实。

## 每页先有值得表达的内容

- 先确定目的、主证据、必要解释、关键数据、图源及跨页衔接，不先画漂亮空壳再填字。
- 正文保持选定参考的高科学信息密度、充实框架与主辅图关系，图、定量对照、必要流程/公式及解释共同承载内容。不能靠一幅巨图加空泛两句、放大字号、重复标签或长逐字稿撑页面；辅图须补充具体认识，局部留白须服务阅读。
- 背景可用场景图与需求解释，方法用原理/流程与关键条件，结果用原图/图表与定量对照，机制用多图证据与关系示意。按论文选择，不能每页相同网格。
- 背景装置、计算域或机制关系需要额外图解时，先明确所要解释的对象，再准备独立透明示意素材。
- 封面和结束页遵循自身用途，不为提高密度塞入正文。全文详略服从听众和时长。

## 版式与信息密度

先按论文的论证顺序明确每页要讲清的关系，记录与主结论直接相关的方程假设、采样条件、证据和误差口径。正文沿用同一套公共框架，并从所选模板中按关系选择内容页型。方法页可用分支流程、时间轴和就近公式；算例页可将原始多面板图与相应的条件、采样和指标对齐；比较页可用相同量纲和标度的并列图或上下证据条；综合页可用矩阵对应结论、原始证据和适用边界。围绕同一比较对象的页面可以复用版式。

每个区域应承载独立的科学信息。优先利用留白补足读图所需的初边值条件、对照范围、数据来源或定量比较。多图场景先选原文中相互补充的图或子图，需要解释计算关系时可加入可编辑示意，适合真实视觉表达的辅助图可另外生成并标明示意。按图形可读性安排面积和字号，避免重复信息、装饰图与相同分栏连续套用。封面、目录与致谢按各自功能控制密度。

生成前和最终渲染后都通看全套。若相邻页的证据关系不同而构图仍相同，或信息由单一大图、重复文案和空白撑起，改用更适合的模板页型，并补齐可从论文核对的关系与数值。逐页核对原图的轴标签、图例、条件和数值，避免为了增加密度削弱投影可读性。

完整新稿默认在封面后设独立目录，采用所选模板的目录页型或同一公共框架。依正式正文列出实际章节名称与可见页码范围。目录的口述从研究问题引出讲述顺序。增删、重排后复核目录、正文页码、配套 PDF 页序、备注、讲稿和时长。用户明确省略目录或只修订局部时，按当次范围处理。

## 透明配图、内容增补与品牌

默认逐页补足主张所依赖的信息，例如设定、假设、采样、观测、对照、误差口径或必要推导。优先增加证据和解释关系，保留一眼可识别的主图与结论，按从主证据到细节安排字号和留白。正文、图例、坐标与表格都要在投影中可读。封面与结束页按功能适量放置书目、主题或来源入口。

对需要视觉解释而论文缺乏适用配图的对象，先给单幅补图定义用途与落位，再以 `transparent_background: true` 调用内置 ImageGen 生成独立 PNG，作为后续整页设计参考与重建素材。让图形能看出要说明的对象或关系，保持简明，配色与线条服从整套报告。需要可编辑的变量名、箭头、精确定量值与图注由原生对象补足。核验实际 alpha 中有全透明背景和可见前景，检查切边与目标底色上的显示。记录工具输出、源文件、用途和逐页位置。在设计记录中将此类区域标为 `auxiliary_image` 并填写 `transparent_background: true`。准确的实验或计算证据继续使用论文原图或原始数值。生成配图就近注明“示意”或“物理背景示意”，使其与论文图表、色标和坐标在视觉上可区分。

用户指定学校或其他组织标识时，从官网或官方视觉识别手册取得矢量或足够清晰的高分辨率原件，记录发布页、素材地址和哈希。按规范选择与模板主色、底色及对比度匹配的官方标准色、单色或反白版本，等比放置并保留留白。规范允许且需要调色时，优先使用可撤销的 PowerPoint 显示效果，保留高清原件并记录效果。先为适用页面预留统一的锚点、尺度、标题安全区和基线，封面和结束页按各自页型安排。将标识作为独立素材嵌入，逐页查看缩至目标尺寸时的细线、字形、对比度和遮挡。

## 生成完整设计

读取当前 imagegen 技能，默认使用内置工具。按输入的逐页内容，每页调用内置 ImageGen 生成一张符合实际画布比例的完整页面设计，包括封面、目录和结束页。设计里要有本页真实标题、主要文案、图表区域与标签，局部插图或拼图总览不能代替独立页面。未看过的本地参考图先查看，使用实际可传入的本地图片，不臆造参数或切换需要API key的CLI路径。

直接参考选定方案的对应页、品牌和科学素材，采用所选参考实际的配色、字体层级、页眉、底线与版式。先把公共组件的位置、尺寸和显示方式写入整套提示；封面、结束页或备份页有另行选定的页型时按该页型处理。截图发生字体替代时以实际参考渲染和当次字体方案为准。每页图文充实且有主次，不受旧占位框限制，不套重复大框、通用卡片或过程标签。

采用本次已确认的标识，保持宽高比及对比度。公共校标位置全套统一。

提示的骨架：

```text
用途：第N页完整科研汇报设计预览，采用用户确认比例
视觉依据：所选参考方案及对应页型；当前用户要求优先
公共框架：沿用整套已选定的标题边界、校徽、页眉、底线与页码；不要为本页另造公共样式
目的与准确文案：……
承接的科学对象或问题：……
关键原图、数据和来源区别：……
构图：主图、必要辅图与定量解释有主次，科学信息密度高、框架充实、比例与留白恰当；不靠放大字撑页面
必须保留：已核实数值、单位、坐标、图例、署名、实际显示的期刊信息及原始素材
辅助素材：使用随附透明场景图或原理图，并标为示意
输出：本页完整画面，一张独立图片，不添加资料外结论
```

选定的真实输出复制到任务 `design_previews/`，原工具输出保留。保存完整提示、参考路径、实际返回文件、生成时间和版本，不能用PPT渲染或手工合成冒充imagegen产物。设计总览另存。

## 审阅与修正

查看每页及全套，检查内容覆盖、有效信息密度、图文对应、字体/字号、配色、重复和阅读顺序。核对文字、数字、单位、轴、图例、来源、署名及封面指标；生成器可能重画原图或品牌字形，不能因整体好看跳过检查。

对低密度、错字、错误数据或风格偏差做针对性修订，保存版本与观察。科学图像素级真实性不能依靠生图保证：生成区域只能提供构图参考，设计记录明确原始素材回填要求，最终用原文件检查。若预览错误会误导观众，修订或明确设为原图占位，不能宣称它通过科学审校。真实标识同样从原文件回填。

全部页面有可用设计后逐页审阅、修订并继续重建；只有用户要求先确认时才暂停等待。有缺页或返回失败时先重试相应页。若内置工具仍不可用，保留已核验的逐页内容和已生成页面，并说明还缺哪一步。跳过整页设计或切换到 CLI/API 仅按用户明确选择处理。PPT 渲染图属于最终检查，不能计入 ImageGen 设计稿。

## 原生对象重建

回填已备齐的原图、官方标识及独立透明示意图。默认程序化编辑参考副本，不使用 computer use；若工具不可用，说明并选择可行的非界面方案。保留视觉骨架，清理示例正文、备注及标识，根据所选预览安排区域。不得把含正文、科学图和品牌的整页设计铺成最终内容背景，也不要留下图中文字再盖一层假文本；独立纯装饰纹理可作为原生幻灯片背景，正文和标识仍独立放置。

- 文字来自准确逐页数据，表格/数据图来自已核验数值；不靠OCR猜文字，更不能从生成曲线反推数据。
- 文字、表格、箭头、框体、数据图及需要编辑的简单关系示意为原生对象，连接关系、轴、图例、单位和公式正确。
- 科学图、校徽、校名按原始字节和比例回填，独立可移动/替换；复杂辅助场景/原理图可为局部图片，不承诺内部像素均可编辑。
- 每页记录区域位置、对象类型及文案/真实素材映射。字体按已记录的无衬线方案统一，构图服从选定设计，事实服从论文。图表/公式等工具接口按当下文档发现，不套历史对象编号。

尽可能贴近选定设计，不仅还原“大致左右布局”。重建前按实际画布标定下列项目，使用已记录的字体方案及一致的坐标单位：

| 项目 | 需要对齐和复核的内容 |
| --- | --- |
| 标题、正文、局部强调 | 文本框边界、字体、字号、字重、颜色、对齐、边距和语义换行 |
| 主图、辅图、图注 | 实际可见图像的尺寸与位置、原图比例、图注位置及字号、标注与图中对象的对应关系 |
| 表格、框体、箭头 | 列宽与行高、单元格边距、表头/正文样式、填色、边线、圆角及箭头落点 |
| 公共组件 | 所选方案中的页眉、校徽、底线和页码，不复制生成图中偶发的尺寸或位置漂移 |

科学原图、准确文案和真实品牌优先于像素相似。宽容器不等于图已放大：`contain` 后仍须检查图像实际宽高与轴标可读性；必要时去除无信息白边、拆分原始子图或调整内部排列，不能为填满框而压扁结构和数据图。

检查继承层与本页是否重复绘制页眉、页脚或装饰线。背景色和浅色分组框置于内容下方；图片放入后再检查白边是否遮住框线，必要时把相关细框置于图片上方。文字、箭头、页码和品牌不应被后加入的背景框覆盖。图层顺序以实际页面可读性为准，不把一套固定绘制顺序机械套到所有页面。

## 对照、核验与交付

实际渲染最终 PPT，按页号与所选预览同尺度并排。逐页校正标题和正文层级、栏目与图框、图注、实际可见图像位置、品牌与页脚，放大核对轴标、字形和标注落点。原图回填、错字修正与等比放置等必要差异写入 `comparison_observations`，每个最终页图的 SHA-256 写入对应重建记录。通览相邻页面，确认科学内容和版式节奏连续。

新报告核验传设计记录、预览目录与 `--require-design-previews --require-pure-speech-notes`；仅当本次有确定品牌且要求每页展示时传入所选品牌与 `--require-every-slide-brand`。PPT每页备注仅写入本页可朗读的paragraphs，提示、来源与制作记录留在逐页数据或工作资料。核验器检查文件、映射、逐页品牌覆盖、纯备注及结构，不能独立证明生图调用真实、科学内容正确或视觉还原完成；另核对真实工具记录、所有渲染页面、正文公共框架一致性和媒体播放。

交付范围和正式目录遵循 [检查与交付](qa.md)。整套报告的 N 张真实选定预览与 N 张最终渲染分目录，明确区分设计依据与成品。局部修订后保留历史工具记录和预览供内部追溯；更新的PPT、PDF及最终渲染才是当前成品，过时预览不进入更新版成果包。并排对照用于检查，不代替任一原始文件。
