# 国自然参考与最终组会样式

国自然答辩原模板提供封面色带、蓝色分栏、红色挑战标签、细边框和结论条。最终组会稿借用了这些组件，并将普通页改为左对齐标题、右上标识和右下页码。两套版式应按所需用途选择。

## 选择参考

1. 用户提供旧稿，或要求“照上次组会风格”时，打开相应已确认的成品。取封面、目录、图表页和总结页作版式锚点。保留该报告的画布、字体、图位、页脚和颜色用法。
2. 用户直接要求套用国自然模板时，优先使用所给源文件。缺少源文件时，使用同仓库的 `nsfc-ppt-component-library` 中的 `assets/nsfc-reference-full.pptx`（39 页脱敏版），按其对应页制作。需要快速挑选代表页型时，可另用 8 页速用组件。
3. 从论文制作组会且没有个人指定模板时，使用[最终组会风格的公开重建样例](../assets/reference.pptx)。样例按 43 页双论文成品的第 1、2、6、10、38、41、42、43 页重建。正文对象和数据采用演示材料。公共页眉的示例标识是可删除的原生对象，真实报告按用户提供的身份与标识配置。

## 组会样式锚点

以下以 1280×720 为坐标系，字体大小为 PPT 磅数。采用原成品的 Zhihe Academic Serif。环境缺少该字体时，选经渲染验证的中文衬线字体并在交付时说明。

| 页型 | 位置与构成 |
| --- | --- |
| 封面和致谢 | 白色画布。全宽蓝带 `#005AA6` 高 198、自 y=246 起。白字居中，封面约 41 pt、结束页约 50 pt。带下主要信息约 28 pt、红色 `#C00000`，身份或辅助信息约 22 pt、深色。上方独立标识区。 |
| 正文页眉 | 左标题约 `[28,12,955,59]`，蓝色粗体 24–27 pt。蓝线约 `[26,83,1229,4]`。右上标识区约 `[1010,16,230,58]`。右下页码约 `[1237,693,33,21]`，13 pt，`#263748`，右对齐。 |
| 目录 | 居中的蓝色标题，四条横向条目示例。每条高约 100、间距约 28。当前章节左边 `#C00000` 数字块、右边浅红底。其余数字块用 `#0070C0`，文字区用浅蓝底。章节回看目录时可切换高亮行。 |
| 三栏问题页 | 用三个方角细框、饱和蓝色栏头和必要的解释图，内容保持有主次。核心结论可用一条蓝底白字横带。 |
| 图证页 | 原图或源数据图优先放左侧主区。右侧用 `#075BA5` 栏头、浅蓝 `#E9F3FA` 条件和结果卡。红线或圈选用于标出真实数据位置。使用尽量贴近正文和原图的白底与细边框。 |
| 对比与总结 | 对比使用两个平行蓝栏、方形小标签和成对图示。总结可以用纵向蓝色圆号、细分隔线和底部浅蓝结论条。 |

红色承担当前章节、科学问题或关键数据的强调。带有历史论文中的机构名、论文图或旧备注的对象，按实际项目的材料重新放置。完成后把实际导出页与对应锚点并排检查，重点对照白底、色带高度、字形、留白、信息密度和页眉页脚。
