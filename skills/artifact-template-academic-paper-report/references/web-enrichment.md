# 联网核验与官方补充素材

## 何时执行

每篇新论文汇报都主动联网核验作者及期刊资料、查找官方附件与相关素材。作者/期刊信息更新或用户要求补充素材时也执行。仅修改既有讲稿或局部版式时保持原修改范围；不涉及新事实、作者/期刊更新或素材补充时，无须重新检索或重做封面。网络或授权访问不可用时记录具体缺项，继续已能完成的部分。

## 作者中文姓名与身份

1. 从论文全文提取作者英文署名、机构、共同一作/通讯标记，优先核查封面及作者介绍页将展示的人。国内团队作者主动寻找对应中文姓名，其余作者按相关官方资料处理，不仅根据所属国家判断姓名语言。
2. 搜索英文全名、论文题目/DOI、学校或机构；优先学校个人主页、研究机构/实验室成员页、官方成果新闻和本人明确关联的 ORCID。结合单位、研究方向及同一论文确认身份，避免同名混淆。
3. 保存英文署名到中文姓名的对应、职务/称谓、来源 URL 和核验日期。共同通讯作者不可漏掉；作者职称和作者角色分别核验。
4. 无法确认中文名时保留论文原文署名，工作资料注明“中文名未核实”。不凭拼音拼汉字，不把博士后写成教授。姓名已核实则在封面/作者页和讲稿同步使用恰当的中文姓名及称谓。

## 期刊指标与封面

默认查制作时最新可核实的已发布指标；用户指定论文发表年份或某年度时按其要求查询。通过期刊正式名称和 ISSN 确认同一期刊，避免混入同系列或同名刊物。

- **影响因子**：优先 Clarivate JCR 或出版商期刊官方指标页。记录 JIF 数值和数据年份，不能用网页更新时间、报告发布年份或论文年份代替。5-Year JIF、CiteScore 等另行命名，不冒充 JIF。
- **中科院分区**：优先[分区表官方网站](https://www.fenqubiao.com/user/Help.aspx)或授权机构访问。封面以大类分区为主，写大类学科、区数和版本年份；需要补充小类时明确标成小类。Top 标识只有核实后才展示，不把大类与小类中较好的一个混写成无学科的“一区”。
- **JCR 分区**：使用 [Clarivate Journal Profile](https://journalcitationreports.zendesk.com/hc/en-gb/articles/28351430970001-Journal-Profile) 所示对应学科和数据年份的 JIF Quartile。多学科有不同分区时，封面选与论文方向直接相关的学科，工作资料保存其余结果；不静默选最好的一项。它与中科院分区分别命名。
- **年份表达**：按照 [Clarivate JCR 引用说明](https://journalcitationreports.zendesk.com/hc/en-gb/articles/28351332957201-Citing-the-Journal-Citation-Reports) 标明指标数据年份。中科院版本年份与 JIF/JCR 数据年份可以不同，分别写清楚。

已核实的封面指标可按以下格式显示；只保留有依据的行，未核实项目从观众页面省略，不显示占位值或占位文案。

```text
期刊：正式刊名　发表：YYYY-MM-DD
影响因子：X.X（YYYY JIF）
中科院：大类学科 X 区（YYYY 版）
JCR：相关学科 QX（YYYY 数据）
```

保留所选深蓝参考系列的封面风格与可读字号。期刊与已核实指标可放简栏，未找到、不可访问或未核实的项目不印在封面、正文或讲稿中，不显示“待核实/暂缺”。完整来源、学科与检索状态保存在metadata及工作记录，不写入PPT备注；仅当缺项影响使用或用户询问时在交付说明简述。第三方汇总页与搜索摘要只能辅助定位，不能单独确证指标。访问报错或登录限制不等于未收录或已核实。

## 主动寻找补充材料

从目标论文的出版商页面进入，而非只搜索整本期刊。检查 Supplementary Information、Supplementary Data/Table、Supplementary Video/Movie、Extended Data、Source Data，以及 Data/Code Availability 所指向的官方资源。记录找到了什么、是否取得文件、内容是什么及适合放在哪页。

再搜索同一论文的团队/机构成果页、官方新闻、作者解读及直接相关的研究背景。必要时查看期刊官方 News & Views 等关联内容。可选用实验装置、制备过程、原位视频、额外证据图或直观应用材料来解释正文，不用无关素材增加工作量印象，也不把宣传文案当作实验结论。

对于 Nature 系列等出版商，附件入口通常在目标文章页面的相关内容区，但名称和位置按实际页面确认；不能由同系列期刊的通用说明推断某篇论文一定有视频。

- 原图、额外数据和影片保持科学内容、坐标、比例尺及单位；记录原论文与附件各自的来源。
- 视频优先取得合法可访问的原始文件并嵌入，记录时长、播放速度和剪辑方式，播放时间计入汇报预算。不能把存在下载链接视为已取得或已播放。
- 无法取得文件时可保留官方入口供用户查看，并明确它是在线入口；不将网页链接称为已内嵌视频。没有相关视频也可以正常完成报告。
- 官网、机构页面、补充资料、评论解读各有用途，选择能说明具体问题的材料；未使用的候选写简短原因，不额外强加“附件页”或改变已指定总页数。

## 可追溯记录

在 `metadata` 中保存作者映射、期刊指标和补充检索清单。每项有来源标题/URL、核验日期和状态（已核实、未找到、不可访问、不适用）；指标记录体系、数据/版本年份与学科。附件再记录类型、文件路径（若已取得）、关联图/页面、用途及是否选用。逐页 `sources` 引用实际使用的资料。

这些记录供事实审查与后续修改使用；现有核验脚本不认证中文姓名、具体期刊分区或附件内容真实性，必须联网读原始来源并人工/代理复核。新的核验不会覆盖无关品牌档案或修改保留的原始模板。
