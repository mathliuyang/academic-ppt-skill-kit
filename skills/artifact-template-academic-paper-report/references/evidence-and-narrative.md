# 论文证据与汇报叙述

## 开始时确定的信息

先读取论文、当次要求和已有报告资料。已知的听众、场景、时长、汇报人和品牌直接沿用；仅在缺失信息会改变结果时补问。默认中文科研文献汇报，页数和详略按论文及目标时长决定。课程截图中的打印份数、汇报时间等是当次约束，不提升为所有报告的固定规则。

先写出研究问题、作者采取的策略、主要证据和贡献，再选择页型。大部分报告可以从相关背景进入问题，随后说明方法、关键结果、解释和综合评价；不必为每篇论文强行套满这些章节。短报告可以压缩常规制备与表征，把时间留给论文最有价值的结果及其证据。

## 应用背景与研究问题

- 应用研究的前几页交代研究对象服务的具体应用、运行或使用条件，以及这些条件产生的材料或方法要求。基础研究从相关现象、已有解释及待解决的科学问题进入，不硬套产业场景。再用已有工作中的具体不足引出本文选择；背景只保留能解释本篇研究必要性的内容，避免宏观介绍和实验结果各自展开却互不承接。作者团队信息按需要放封面，完整核验记录留在metadata，不为其单独占用尚未建立问题的背景页，也不加入PPT备注。
- 区分背景材料、基准体系和本文改性后的对象。背景讲已有材料的不足时，图与数据须属于该基准；到解释本文干预时再引入新结构，避免提前用改性结构替代基准。辅助示意明确其适用对象和性质。
- 把性能要求写成有关系的句子，例如某一环境或参数怎样影响传导、稳定性或加工，再说明结构选择和对应测量。不能只并列“高性能、稳定性、应用”等关键词，也不能靠增加过渡词掩盖对象变化。
- 后续实验承接前面尚需回答的具体问题：上一组结果支持了什么，下一组比较增加了什么条件或考察了什么性质。综合结果再回到开始提出的要求；每页同时保留关键条件和数据，不用组织说明替换实验信息。
- 汇报可按理解需要重排实验页。展示顺序不等于作者实际开展实验的先后；原文未报告时间顺序时，不写“作者先做A，再做B”。屏幕标题和概述写科学对象、条件及关系，不印“逻辑主线”“论证顺序”等备稿标签；讲稿以对象和结果自然承接。
- 背景图用于解释应用装置、工作部件或研究条件。联网优先查官方和原始来源，必要时生成独立辅助示意；通用应用场景不能被说成论文材料已在该设备中使用，生成图不能替代实测曲线或化学结构。完整图源和示意性质保存在逐页sources与工作记录，保持正常文献汇报的页面表达；PPT备注只保留纯讲稿。

## 论文信息核验

制作每篇新论文汇报时主动联网，不能只依赖本地 PDF 或历史值。按 [联网核验与官方补充素材](web-enrichment.md) 打开出版商论文页，检索作者和期刊资料、官方附件/视频及相关解读。仅修改既有讲稿等任务仍遵循当前修改范围。

以论文 PDF 和出版商页面为基础，核对题目、期刊、作者、共同一作、通讯作者、团队单位和在线发表日期。国内团队作者优先查找对应中文姓名；在官网资料中结合单位、研究方向及对应论文确认身份，不能根据拼音猜字。教授／博士等称谓需有官方依据。在线发表、接收和卷期日期分别保留正确含义。

封面显示期刊及已核实的指标，保留JIF、中科院和JCR各自的体系、必要学科及数据/版本年份。未知项目只在工作资料记录检索状态，从观众页面省略，不写推测值或占位说明。

## 原图与数值记录

对每个核心证据保留来源记录：论文文件或 URL、PDF 页码、图号、子图、裁剪位置，以及该图支持的表述。PDF 页码用 1-based；裁剪坐标同时说明单位、坐标原点和页面尺寸，避免后来提图裁错。对数值记录原值、单位、比较对象、测试条件、样品／材料尺度和来源位置。

从原始 PDF、出版商的图文件或补充材料提取科学图。按子图裁剪、放大和标注可以提高可读性，但必须保留结论所需的坐标、曲线、图例、颜色、比例尺和刻度。完整论文首页可放入封面图文区域或信息页，按比例显示，不把它称为期刊封面。每个关键图都对照原文查看一次，避免沿用历史生成截图中错误的曲线颜色和坐标范围。

论文比较不同测量、模型、方向或尺度时，在解释中保留区别。例如不同测试给出的带隙不强行等同，纳米柱压缩的应变不能扩展成块体拉伸性能。这些条件只在影响结论的位置准确说明，无需反复加入审查式口号。

## 背景和辅助素材

制作汇报时，可以联网搜索并选用与论文内容相关的图片，也可以使用内置生图功能制作应用场景图、原理示意图等辅助图片。根据讲述需要选择或结合两种方式，配图应帮助解释内容，并与模板的配色、排版协调。

应用背景应与当前论文的对象及性能有直接联系。先查论文引言、讨论和所引用的相关材料研究，再寻找对应的官方图、实验素材或可理解的场景。另一个材料能做某器件，不证明当前论文材料已经能做同类器件；以“已有研究”“潜在方向”表达其实际证据层级。

面向学术新人的背景用直观场景说明性质为什么有用，并简要解释材料与场景的联系。可以用 imagegen 生成辅助场景或原理示意，记录提示词和用途；不要生成实验图、曲线、原子像或作者团队照片。辅助配图服务于解释，不能抢走核心论文图的视觉地位。只为外观增加复杂线网、无关物品或重复插图，通常会降低清晰度。

每篇新报告主动检查论文官网的 Supplementary Information、Supplementary Data、Supplementary Videos/Movies、Extended Data 及相关内容入口。若有帮助理解方法、现象或机制的官方材料，选入合适页面；有素材不等于全部塞入 PPT，选择理由记在工作资料。直接相关的团队/机构研究解读、新闻或应用资料可辅助背景与讲述，不能替代原论文证据。

采用视频时优先使用论文官网、补充材料或研究团队官方的实验视频。原理动画明确标为示意，其路径、速度和因果关系应有依据。默认不加入文字逐条入场动画。记录视频来源、播放速度和剪辑方式；两个记录时长不同的视频不能仅凭同步画面推进速度比较真实变形速率。

## 屏幕文案与口述正文

屏幕文案直接说明研究对象、处理、观察及其关系，解释贴近对应图，使用自然简洁的中文学术表达。自然的口述承接是让前句对象成为后句解释或处理的对象，不是逐句直译、照读标题或堆连接词。内部purpose、讲述主线与核验规划保留在数据中，不变成“论文主线”“论证顺序”“本页要点”等屏幕标签。

简洁文案与高科学信息密度同时成立。参考所选系列，将主证据、恰当辅图、流程或定量对照和必要解释组织成充实框架，主辅图比例合理，避免一幅巨图加两句宽泛总结。密度来自有用信息，不能靠调大字号、重复标签、无关图片或长逐字稿填满。准确内容先于生图布局，生成像素不成为新事实；各页结构服从研究对象，不套同一种网格。

口述正文可以从前到后连贯练习，保留必要的专业术语并用短句解释。以当前页结果自然引出下一页，不机械重复“首先、其次、最后”或每次都说“本文”。英文题目不作为必须朗读的正文；中文标题和通俗解释优先。简洁不能删掉听众理解所需的联系，也不能用指图指令代替真正的解释。

前句解释或得到的对象自然承接到后句，交代必要条件、处理改变及结果支持的判断。已核实事实可直接陈述；只有需要区分外部研究、作者解释与汇报者判断时才说明归属，不反复说“来自原文”。局限或后续问题应落在本研究的具体证据上，未提供依据或用户要求时，不额外加入系统成本、风险清单或逐页否定式提醒。

逐页正文、时长、指图／播放提示、强调词及来源分别保存在讲稿数据中，按 `references/speech-data.md` 和对应 schema 生成。PPT 备注、Word 和纯讲稿 PDF 共用同一份口述正文；口述、术语、关键数值、页序或讲稿显示信息变化时，同步受影响的内容和输出。纯版式调整且这些信息不变时，不重新生成讲稿，按 `qa.md` 的局部修改范围复核。PPT备注只保存可朗读的paragraphs，不设提示或来源区域。Word可沿用已选的独立提示样式；纯讲稿 PDF 只保留正文、对应 PPT 页号和关键词加粗。

sources用于内部溯源，保存在逐页数据与工作记录，不写入PPT备注，也不默认转成每页可见全文来源页脚。需要定位证据时使用简短图号；必须区分的外部资料按用途标注。

估计时长包含翻页、停顿和视频。用户要求“只讲5分钟，PPT不精简”时优先缩短讲稿，保留页面；不能为了匹配旧案例擅自改变所有新报告页数。按本人语速试讲后的反馈再调整。

## 综合总结

总结回到开头建立的问题，用少量关键对照回答它。优先保留基准与改进后的同条件数值、对应结构选择及结果支持的认识；必要时用两组证据或小表组织。不同配方、尺度或器件取得的最优结果分别归属，不能拼成一个并不存在的最优样品。

总结覆盖论文完整贡献，连接关键方法、结构／过程变化、核心结果和有依据的意义。选择新的综合关系或必要的小图，不重复堆叠前页所有大图。仅保留能由证据支持的后续问题，与前文统一颜色、字体和版式。结束页独立，并沿用蓝底封面体系。
