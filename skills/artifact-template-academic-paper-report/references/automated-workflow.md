# 论文 PDF 到可编辑汇报：程序化流程

本流程提炼自一套多篇论文的组会汇报，供新任务按需采用；案例的论文、人数、页数和机构不作为默认。用户提供的预览和明确要求优先。默认不使用 computer use。

## 1. 收资料与建立证据链

- 区分论文原文、补充信息、模板 PPT、设计预览 PDF 和用户的新要求；预览中的示意数据、批注、乱码不自动成为事实。先读原文和图注，必要时查出版商原始网页、补充文件和书目信息。对每一项关键结论记录原文位置、样品、对照、数值、单位和测试条件；文献之间测试条件不同不能直接比较寿命或单一性能数字。
- 从科学问题出发规划背景、现有策略及其机制与利弊，再引出每篇研究的设计、合成、核心证据、性能、机制及综合讨论；具体页数与听众、时长和论文内容相匹配。多篇研究可以各有文献信息和可朗读的亮点介绍。章节较长时可使用有当前章节高亮的目录过渡。
- 将策略总结为清晰的分类表、流程图、知识图谱或时间线，列代表性策略、作用机制、优势及局限；内容有论文依据，既不把背景缩成空泛词组，也不把无关论文堆满页面。
- 真实论文图优先：选用必要的制备路线、结构、表征、性能与机制图；从 PDF 或补充文件取得清晰原图，裁分子图时保留轴、图例、比例尺与条件。删去重复图但不要遗漏支撑结论的关键图。需外部素材时验证来源；生成示意不得冒充实验数据或真实微观结构。

## 2. 视觉方案与可编辑构建

- 根据用户提供的设计预览/模板，标定画布、色号、字体、字号、标题、页码、右上标识、页眉底线和正文网格；用户指定国自然风格时读取 `nsfc-ppt-component-library` 的色卡与参考。明确指定字体（例如 Zhihe Academic Serif）需检查可用性与科学符号；不要把某次用户的身份或 logo 沿用到他人。
- PDF 设计预览用于确定页面结构和视觉节奏；最终以核实内容和论文原图替代生图中的科学图、数字、文字与校徽。默认原生对象构建文字、表格、线条、箭头和中文图中批注；复杂原图作为独立可选、可替换图片，不能声称其内部全部可编辑。需要透明辅助插图时可用 imagegen；不强制所有页面生图。
- 图上标注要指向真实图中的正确数据、峰、曲线或结构，配简明中文解释与必要条件，标注不遮挡轴和图例。把标注与正文结合，避免只画圈不解释、箭头指错、或页面重复同一组数据。机制、数值与判断逐项对照原文，不把作者假设或模拟夸成直接观测。
- 正文、目录和总结页在需要时统一标题、校标和页码的位置、大小、颜色及字体，封面和结束页按用户指定的独立风格处理。校标复用实际原对象及其色彩变换，单独复制底层图像可能丢失调色。检查与标题、底部结论及图注的碰撞；不要为填空编造内容。

## 3. 讲稿与同步

- 用共同的逐页数据维护页序、口述段落和时长；PPT 备注只存可朗读正文，Word 与大字 PDF 使用同一口述内容。将跨页过渡写自然，避免冗长免责声明、内部排版说明和机械化口吻；必要条件写进科学叙述，不靠夸大确定性换取流畅。
- 用户直接提供逐字稿且要求替换时保留其表达，只做等价的公式、换行显示处理；用户仅要求修改讲稿、PPT 或 PPT 备注时分别遵守范围。检查讲稿与图、页码、数据和原文一致；发现稿件事实错误或原论文图文不一致要明确指出，未经授权不擅自改写其原话。
- 汇总用户给定的每页计划时长并说明与目标的差异；此为估计而非实际试讲。章节重排、增删页或更换图后重新核对备注和讲稿页序；只调整不影响正文的布局则保留原讲稿。

## 4. 逐页复核、交付和清理

- 渲染全部新页：逐页看标题、字体、间距、密度、图像可读性、标注落点、色彩、层级及公共组件一致性；发现问题修正后重渲染。总览帮助看节奏，不能替代单页审阅。将重要数据和归因回查原文，核对封面身份、作者和单位；把科学上仍不确定之处单独记录，不把制作过程或泛泛免责声明放入观众页。
- 验证 PPTX 能重新解析、主要文字与图形为可编辑对象、图片和备注完整；对逐字稿对比 PPT 备注与 Word/PDF 全文及页号。渲染 Word/PDF，实际检查中文字体、上/下标与分页。渲染器缺字时定位字体和渲染器问题，采用可验证的替代方式，并说明尚未验证的 PowerPoint 客户端行为。
- 局部修改使用工具公开 API；必要时对原文件做受控包级编辑，保留关系、命名空间、备注、母版与未修改内容。比较源文件和输出的包及实际渲染，不声称未经目标应用验证的兼容性。保留源稿，避免覆盖正在打开或可能有未保存修改的文件。
- 正式交付单独文件夹，按要求放 PPTX、对应 PDF、Word 讲稿、大字 PDF 和有授权可分发的必要字体；文件名去掉过程或反复修订标签。核对页数、可读性、同步和文件打开后再清理。仅在用户授权时清理本项目明确的旧稿及中间文件，优先可恢复地移至废纸篓；原论文、补充材料、参考模板和其他项目不动。正在打开的文件先避免移动，确认关闭后再处理。
