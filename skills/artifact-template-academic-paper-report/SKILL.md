# 深蓝学术文献汇报

用准确的论文证据组织连贯的中文汇报，程序化制作或重建可编辑PPT。沿用所选参考系列的配色、字体层级和公共框架，内容区随证据关系变化；图文充实、主次明确、原图保真，讲稿自然承接。

## 任务范围与自动执行

- 用户只给论文 PDF 和要求时，主动读取材料、确定叙事与页面设计，持续制作到可交付。新建报告或整套重设计默认先运行逐页 ImageGen，再程序化制作可编辑成品，全程不使用 computer use。既有报告只改指定页面或讲稿时按授权范围处理；用户明确指定另一流程时以当前要求为准。
- 先读取 `artifact-template.json`、[参考库索引](references/template-library.json) 和用户提供的设计预览或模板。用户指定模板优先。说“直接用国自然答辩模板”时优先使用用户给的国自然原 PPTX；未提供原稿时使用同仓库中 `nsfc-ppt-component-library` 的 `assets/nsfc-reference-full.pptx`，即完整 39 页公开脱敏模板。8 页答辩组件用于快速挑选页型。普通新论文组会在未指定模板时沿用本技能的 8 页组会参考。已有报告保留其身份、字体、比例和公共框架。
- 默认中文、16:9、研究生组会可理解的科学深度；根据材料与时长合理分配页数。未给身份时省略，不沿用示例人物和机构。只为阻断制作的缺失材料或关键要求提问；其余合理假设继续推进。用户要求先审设计时才等待相应确认。
- 需要动画或视频时先核查是否与论文有关；用户只要求查找待确认时，列来源供选择，不擅自嵌入。用户给出新的逐字稿或修改范围时尊重原文和范围；若原文有可核实的事实问题，先保留要求的文本并明确提示，不悄悄改写。
- 项目沿用已有目录和用户约定。完成并核验后，按[交付与验收](references/qa.md)整理；旧稿或工作文件仅在用户授权清理时移除，原始论文、补充材料和参考模板保留。

## 协同规则

- 内容、视觉和实现各有依据：`nature-paper2ppt`可用于科学问题、证据与叙述组织；本skill负责选定参考、信息密度及生图/重建流程；PPT的接口、运行时和打包校验遵循当前Presentations规范。通用的短文案预算、结论式标题偏好或旧工具默认不替代本次明确选用的模板要求。
- 屏幕标题明确研究对象、变量、性质或有依据的结果关系。专业陈述式标题和证据充分的结论式标题均可，不强制问句、宣传化标题或所有页面同一种句式。高信息密度来自必要图证、条件、对照与解释，不靠大字号、无关插图或长逐字稿撑页。
- 一套报告先固定公共标题区、品牌区、页眉、底线和页码；总结与讨论属于正文，默认共用这一框架。封面、结束页和备份页按所选系列及用途定义。内容区可借鉴其他页型，但不继承另一套公共组件。
- 尽可能还原选定设计的字体、字号、字重、色彩、间距、框体与图位。已核实文案、科学原图、真实品牌及其比例优先；当前用户认可的修订高于早期生成图的偶发样式。必要差异记录并复核，不无条件复制生成像素。
- 文字、表格、简单关系图、箭头和框体为原生对象；复杂科学图和辅助示意为独立可替换图片。不把含正文、数据或品牌的整页设计铺成最终内容背景；独立纯装饰纹理可作为原生幻灯片背景，正文和标识仍独立。

## 按需读取

- 选参考及排版：查看用户的模板或[按最终组会稿重建的可编辑参考](assets/reference.pptx)和[页型索引](references/template-library.json)。
- 国自然原模板与最终组会样式是不同用途的参考；先读[样式选择与页面锚点](references/final-report-style.md)，按当前参考定位封面、目录、图表及总结。
- PDF 论文自动制作及本次经验：读[程序化制作与交付](references/automated-workflow.md)。新建报告或整套重设计先读[整页生图与可编辑重建](references/imagegen-preview-first.md)，对应记录见[逐页设计记录](references/preview-data.md)。
- 理解、选图和组织背景：读[证据与讲述组织](references/evidence-and-narrative.md)。表述要贴合本次结果，保留原文专业术语、数值与限制。
- 选择身份：采用当前确认的汇报信息及授权素材。页码、标识、标题和底线以本套报告公共框架为准。
- 新论文、作者/期刊信息更新或补充素材：读[联网核验](references/web-enrichment.md)，核查官方来源、附件和视频。纯布局修改不触发无关检索。
- 写或修改讲稿：读[逐页数据与工具](references/speech-data.md)。PPT每页备注只放 `paragraphs` 中可直接朗读的纯讲稿，不加标题、用时、提示、来源或分区标签；与Word及大字PDF共用同一口述正文，其他记录留在逐页数据和工作资料。
- 换入或补充论文、要求全图、只改指定页面或全篇页码：读[增删文献与局部改版](references/revise-existing-deck.md)。
- 导出与局部修改：读[检查与交付](references/qa.md)，按最终受影响范围复核。

## 从论文到汇报

以下是新报告或整套重设计的流程。已有报告局部修订直接按[局部修改与复核复用](references/qa.md#局部修改与复核复用)处理，先检查当前文件是否已经满足要求，再决定必要改动。

1. **建立科学问题与证据关系。** 读论文及当次材料，确定应用/现象、具体不足、作者策略、关键对照、结果和贡献。新论文主动联网核查出版信息、国内作者中文名及身份、已展示的期刊指标与版本年份，检查官方补充材料和相关解读。未知信息留在工作记录，不补造或印成待核实占位。
2. **确定逐页内容和真实素材。** 在同一份逐页JSON中保存目的、准确文案、图源、数据、条件、时长和口述正文。背景建立理解后续设计所需的装置、材料和指标关系，实验回应前面的问题；多篇文献可合并共同背景，按互补问题串联研究，综合页比较设计与证据。原始图优先，解释缺图时可检索可靠素材或生成独立原理示意，不能替代实验证据。
3. **先做逐页整页设计。** 将每页已核对的标题、文案、数据、图源和对应模板页送入 ImageGen。每页生成一张包含真实汇报内容和构图的完整设计稿，包括封面和结束页。检查全套页序、版式、术语、图文位置与统一性。默认生成并自审全部页面后再开始可编辑重建；用户要求先审设计时把整套预览交给用户。用户明确指定直接沿用的成套设计稿或明确跳过生图时才按该要求执行。
4. **原生编辑与真实素材回填。** 使用当前 Presentations 工具和程序化方法，在模板或组件的副本上建立可编辑文字、表格、框、箭头与批注；论文原图、校徽作为独立可替换图片，保留比例和真实来源。清理案例身份、重复继承层及遮挡；必要时参照[程序化制作与交付](references/automated-workflow.md)处理源文件、图表标注和格式。
5. **渲染对照并同步受影响讲稿。** 实际导出PPT，与选定设计逐页比较，修复构图、字体、图位、图注和公共样式偏差。口述以对象、条件和结果自然接住相邻页，不靠连续的看图/翻页口令。口述正文、术语、关键数值、页序或讲稿显示信息改变时同步相应输出；纯布局修改且这些信息不变时保留讲稿。
6. **核验并交付。** 按QA范围检查最终PPT、配套PDF和PNG，讲稿被修改时检查对应Word/PDF；有媒体时验证实际播放及计时。新报告全页检查，局部修改检查改页和所有受影响页面，未改且可证明相同的页面可复用已完成记录。更新受影响的总览、对照、清单和ZIP，正式交付不混入过时预览。定稿整理依用户范围进行，保留原始论文、补充材料和参考。

## 工具与交付约定

- 先发现当前 Codex 的演示工具和文档运行时。可用时遵循 Presentations、Documents 和 PDF 工具指引；缺少专用工具时可用 Python 和本机 PDF/渲染工具，参照[程序化流程](references/automated-workflow.md)。不要将本机绝对路径、插件版本或历史对象ID写成通用运行依据。
- `scripts/build_speech_outputs.py`生成同步Word及大字纯讲稿PDF。后者仅含口述正文、PPT页号和关键词强调；长稿按阅读需要增加页数，不删正文或压成小字凑页。
- `scripts/verify_report.py`检查canonical、讲稿同步、编辑性、图片、品牌和设计映射。凡新交付或修改PPT备注，默认传 `--require-pure-speech-notes`，检查整页备注仅含纯讲稿；实际采用逐页生图时另使用设计记录及所选参考；仅在真实品牌已确定且要求逐页展示时使用 `--require-every-slide-brand`。脚本不认证生图调用真实、科学事实、字体视觉、图层或还原程度；必须结合真实工具记录与实际页面。
- 默认交付可编辑 PPTX、同版预览 PDF、逐页同步的 Word 和大字讲稿 PDF；按用户要求增减。保存按页序编号的 ImageGen 设计稿，提供可查看的整套预览。最终 PPT 渲染图与设计稿分别保留，独立 PNG 按需交付。局部修订只重建和导出受影响的材料，历史生图留在内部记录，不冒充本轮新图或进入更新版成果包。
- 仅在当前身份和品牌已确定并适用时放置用户有权使用的完整标识。
- 来源、作者及期刊核验、指图提示和制作检查保存在 `report.json` 与工作记录，不写入PPT备注或额外备注文本框。观众页面仅显示必要图号、单位和条件，不重复全文书目、内部核验清单或无依据的风险评论。其他协同技能的通用“来源写入备注”建议不替代本模板的纯讲稿约定。最终回复报告实际完成结果及影响使用的限制。
