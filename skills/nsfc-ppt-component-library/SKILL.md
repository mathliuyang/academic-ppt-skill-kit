# 科研答辩 PPT 组件库

优先使用用户提供的模板。本库提供可直接打开的[七页组件 PPTX](assets/components-candidate.pptx)及[色卡和字号](assets/palette-and-type.json)，用于论文组会和科研答辩。选择与内容相匹配的组件，采用当前已确认的署名、标识及论文素材。

- 一套报告先统一标题、边距、底线、正文层次和页码。用相近参考页标定主题色与强调色的用途。封面和结束页可保留独立布局。关于组件映射见[页型表](references/components.md)。
- 默认程序化制作。可导入组件或复制原生框体、文字和箭头，保留参考中适用的母版和版式。论文数据图、标识和复杂科学原图作为真实素材独立放置，并加可编辑说明。
- 改已有 PPT 时，先检查当前页面和备注。只改指定页或明确授权的全局组件，验证其他正文区域及备注。检查实际可见标题、页码、标识和继承对象，避免重复叠放。
- 交付前渲染改页和受公共样式影响的页面，检查字体、页码、图层、字距及真实可见字号。工具能力以本次实际运行结果为准。
