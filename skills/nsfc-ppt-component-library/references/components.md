# 国自然原模板的公开答辩组件

[可编辑组件](../assets/components-candidate.pptx) · [样例 PDF](../assets/components-reference.pdf) · [八页总览](../assets/components-preview.png)

原参考是 39 页国自然项目答辩稿。公开组件保留代表页的居中蓝色章标题、带线托底的封面、红色挑战标签、三栏技术方案、成果边框及致谢结构。使用占位文字和自绘图替换了原内容。

| 公开页 | 原参考页 | 组件 |
| --- | --- | --- |
| 1 | 1 | 白底与通栏蓝色标题带，主信息及署名上下分区 |
| 2 | 2 | 纵排提纲标题与横向章节条 |
| 3 | 8 | 三条红色挑战标签、灰底内容框和蓝色研究目标条 |
| 4 | 12 | 科学问题说明、红色竖标签和验证区 |
| 5 | 18 | 三栏技术图文与下方竖向方案标签 |
| 6 | 25 | 圆角蓝条与两项成果卡 |
| 7 | 26 | 虚线成果框与竖向标签 |
| 8 | 39 | 白底、红色致谢语和蓝色项目标题 |

原组件采用 16:9。标题的主要蓝色为 `#005AA6`，常见蓝色栏头为 `#0070C0`，关键问题与提示采用 `#C00000`。其它尺寸、渐变、描边和英文字形以实际对象为准。原稿中文主要用微软雅黑。公开 PPTX 保留该字体设置，附带 PDF 以经渲染核验的中文无衬线替代字体导出。

做论文组会并希望沿用组会成品时，采用论文汇报技能的成品样例。它保留上述组件的用色，并采用左对齐中文衬线标题、右上标识和右下页码。
