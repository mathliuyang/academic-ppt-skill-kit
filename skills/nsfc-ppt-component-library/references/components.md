# 公开组件使用

| 页 | 组件 | 适用内容 |
| --- | --- | --- |
| 1 | 封面色带 | 正式汇报标题和身份 |
| 2 | 三层背景及结论条 | 应用需求、限制和影响 |
| 3 | 问题框与难点区 | 主问题与具体挑战 |
| 4 | 并行图文及方案 | 多条研究路线或多个任务 |
| 5 | 原图对照 | 两组结果、原始条件和结论 |
| 6 | 大小图组合 | 科学贡献和支持证据 |
| 7 | 色卡 | 核对主色和强调色 |

画布为 16:9。原生组件可在支持 PPTX 的软件中编辑。具体字号与字形按安装的字体和导出效果校准；无微软雅黑时，可选本机已验证的 CJK 字体。复杂原图不应被拉伸或用假数据替代。组件中的提示文字需要按本次内容替换。

已有组件文件可直接用。如需重新生成，使用当前 Codex 工作区提供的 Node 与 `@oai/artifact-tool`。将其 Node 模块根目录传入 `RUNTIME_NODE_MODULES`，运行 `node scripts/build-components.mjs /绝对输出目录`。该脚本生成可编辑 PPTX 和单页预览，普通使用无需运行。
